┌────────────────────────────────────────────────────────────────────────────┐
│ COMO COMEÇAR (5 MINUTOS)                                                   │
└────────────────────────────────────────────────────────────────────────────┘

  1. Instalação (2 min)
     $ cd colaborador-digital-equipamentos
     $ python -m venv .venv
     $ source .venv/bin/activate
     $ pip install -r requirements.txt
     $ cp .env.example .env
     # Editar .env com sua chave OpenAI

  2. Testes (1 min)
     $ pytest tests/ -v

  3. Execução (1 min)
     # Terminal 1: Servidor MCP
     $ cd "Servidor MCP (Compartilhado)"
     $ TEMA=equipamentos python mundo.py

     # Terminal 2: Agentes
     $ python main.py

  → Ver README.md → Troubleshooting

  → Editar .env com sua chave
  → Ver README.md → Troubleshooting

  → Servidor sobrecarregado, aguarde
  → Ver README.md → Troubleshooting
