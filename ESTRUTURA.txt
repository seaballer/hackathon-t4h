REGRAS DE NEGÓCIO

• Limite de compra autônoma: R$ 500
• Dias para cobrança de devolução: 5 dias úteis
• Dias para escalar devolução: 10 dias úteis
• Período máximo de empréstimo: 7 dias úteis
• Estoque mínimo: 3 itens

═══════════════════════════════════════════════════════════════════════════════

RESILIÊNCIA

Retry:
  • 503 Service Unavailable: retry com backoff (0.5s, 1s, 2s)
  • Máximo 4 tentativas

Idempotência:
  • Hash de evento_id + tool + args
  • Cache em memória
  • Verificação antes de repetir (504)

Circuit Breaker:
  • 5 falhas consecutivas: pausa 3s
  • Eventos preservados no checkpoint

COMO USAR

1. Instalação:
   python -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   cp .env.example .env
   # Editar .env com sua chave OpenAI

2. Testes:
   pytest tests/ -v

3. Execução:
   # Terminal 1: Servidor MCP
   cd "Servidor MCP (Compartilhado)"
   TEMA=equipamentos python mundo.py

   # Terminal 2: Agentes
   python main.py
